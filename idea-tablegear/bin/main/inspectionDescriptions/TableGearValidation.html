Validates TableGear configuration files and detects syntax errors, invalid properties, and type mismatches.

This inspection checks for:

  • Missing or invalid key=value syntax
  • Unrecognized configuration properties
  • Duplicate property definitions
  • Invalid boolean values (must be yes/no or true/false)
  • Invalid enum values for properties with restricted options
  • Line continuation syntax errors

Supported property types include string, boolean, enum, list, path, and SQL values, with validation rules specific to each configuration mode (database, elasticsearch, json, common).


# Valid configuration examples
package_name=com.example.demo
generate_all=yes
swagger_version=3
type=elasticsearch_mapping
url=http://localhost:9200

Configure inspection severity and enable/disable specific validation rules in the inspection settings.
